How AirGuard Works

map

1. Retrieve Location

We fetch current weather patterns and specific atmospheric pollutant readings from satellites and local stations via Open-Meteo API.

memory

2. Run AI Inference

Our local serverless Random Forest regressor analyses inputs to predict the consolidated Air Quality Index (AQI) based on historical models.

favorite

3. Generate Advisories

We generate detailed precautions for different citizen groups to help limit exposure to air toxicity in real time.
